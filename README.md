# webЯcade Applications: Sega Dreamcast (flycast)

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

This repository contains a [webЯcade](https://www.webrcade.com) application for the [Sega Dreamcast](https://en.wikipedia.org/wiki/Dreamcast).

The underlying emulator is a WebAssembly build of [flycast-wasm](https://github.com/nasomers/flycast-wasm), a fork of [flycast](https://github.com/flyinghead/flycast) using a from-scratch SH4-to-WASM dynamic recompiler.
